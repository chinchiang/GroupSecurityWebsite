# Phase 2 — App Shell and Pages

## Delivered

- Locale routes under `src/app/[locale]/*`
- Dark sidebar, top bar, breadcrumb, search, language switch, demo identity, CTAs
- Role-aware dashboard with metric metadata and drill-downs
- Core list/detail: risks, incidents, regulatory clock, assets, vulnerabilities, plants, suppliers, knowledge, service requests
- Generic DataTable (search/filter/sort/pagination/column visibility + mobile cards)
- Global search with authorization filtering
- Loading / empty / error / access-denied states
- Demo banners and disclaimer/about pages

## Responsive / a11y baseline

- Skip-to-content, focus styles, semantic headings, reduced motion
- Status communicated with label + icon + text (not color alone)
